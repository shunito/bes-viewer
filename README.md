# UniBraille Viewer

UniBraille Viewer は、日本国内で広く利用されている BES ファイルや、世界的に普及している BRF などの点字ファイルをブラウザ上で直接閲覧するためのビューアアプリケーションです。
バイナリ形式の BES ファイル、および各種テキスト形式の点字ファイル（BRF, BRL, BSE）を Unicode 点字文字に変換し、ブラウザで読みやすいレイアウトでレンダリングします。また、「晴眼者むけの読み」の表示/非表示の切り替え機能も搭載しています。

## 対応ファイルフォーマット

本アプリケーションは、日本国内およびグローバルで広く普及している以下の点字データフォーマットに対応しています。

- **.bes**: 日本国内で広く利用されている「点字編集システム」などの標準的なバイナリ形式の点字ファイル。
- **.brf** (Braille Ready Format): 英語圏を中心に世界的に最も普及しているテキスト形式の点字ファイル（NABCC / ASCII Braille 準拠）。
- **.brl**: 主に北米等で交換用データとして利用される、BRFと同様のテキスト形式の点字ファイル。
- **.bse**: 日本国内の点訳ソフト「BASE」や「ういんびー」などで採用されているテキスト形式の点字ファイル。

## 主な機能
- **点字ファイルの読み込み**: `<input type="file">` 経由、またはクエリパラメータ `?url=...` による外部点字ファイルの読み込み。
- **点字レンダリング**: Unicode点字フォント（Apple Braille など）を用いた美しい点字レイアウト表示。
- **読み仮名表示**: `tenji` ライブラリを使用した、点字から日本語（読み仮名）への変換および表示。
- **目次ナビゲーション**: 見出しの自動抽出によるページおよび章へのジャンプ機能。
- **PWA（Progressive Web App）対応**: オフライン環境でもビューアを起動して利用可能。

## 主な技術スタック
- **フレームワーク**: Vue 3 (Composition API / `<script setup>`)
- **ビルドツール / バンドラー**: Vite 8 / Rolldown / esbuild
- **プログラミング言語**: TypeScript 6
- **UIライブラリ**: Oruga UI (Bulmaテーマ)
- **テストフレームワーク**: Vitest
- **Lint**: ESLint 10 (Flat Config)

## セットアップとコマンド

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（ホットリロード有効、デフォルト: localhost:5173）
npm run dev

# 本番環境向けのビルド（出力先: dist/）
npm run build

# 本番ビルドのローカルプレビュー
npm run preview

# コードの静的解析（Lintチェック）
npm run lint

# ユニットテストの実行（Vitest）
npm test
```

## 推奨エディタ設定 (VS Code)

本プロジェクトは Vue 3 および TypeScript 6 で構成されています。快適な開発環境のために以下を推奨します。

- **推奨拡張機能**: Vue 3 公式の **Volar** (Vue Language Features) を有効にしてください。
- **以前の拡張機能の無効化**: 旧バージョンの Vue 2 向け拡張機能である `Vetur` は無効化またはアンインストールしてください。
